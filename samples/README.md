# Fictional phishing examples for awareness training

These examples are deliberately non-operational teaching artefacts. They use fictional identities and reserved example domains, contain no working malicious links, collect no credentials, and have no real attachment. Do not send them to real people as phishing lures. Use them only to teach employees how to identify suspicious signals.

## Example 1 — Employee reward lure

Learning points: reward-based social engineering, artificial deadline, external Reply-To, and a misleading double-extension attachment filename.

## Example 2 — Account security alert

Learning points: fear and urgency, unexpected account-verification request, and a Reply-To domain mismatch.

For any real awareness campaign, obtain authorization and use a harmless landing page that records only approved training events. Never collect real passwords or deploy malware.
