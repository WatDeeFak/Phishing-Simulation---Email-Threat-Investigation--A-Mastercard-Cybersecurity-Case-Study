# Diagrams

The `.mmd` files are Mermaid diagrams and can be rendered directly by GitHub in Markdown files that include Mermaid code fences. SVG/PNG previews of the principal diagrams are available under `../visuals/`.

- `attack-flow.mmd`: two potential paths (credential harvesting and malware delivery).
- `evidence-correlation.mmd`: how the evidence groups support an attack hypothesis and impact assessment.
- `incident-response-flow.mmd`: evidence-based response sequence.
